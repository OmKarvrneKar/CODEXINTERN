# House Price Prediction

This folder contains `house_price_prediction.py`, a complete script that:

- Loads the California Housing dataset from scikit-learn (no manual downloads).
- Performs EDA and visualizations (histograms, correlation heatmap).
- Preprocesses data (train/test split, StandardScaler).
- Trains a Linear Regression model and evaluates it (MSE, RMSE, R²).
- Plots Actual vs Predicted house values.

How to run (PowerShell):

```powershell
python "E:/in/House_Price_Prediction/house_price_prediction.py"
```

Dependencies are listed in `requirements.txt`.

You can initialize a git repo at `E:/in` and push this folder to a remote (see instructions in the repository root `.gitignore`).
